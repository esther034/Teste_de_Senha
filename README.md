# Teste_de_Senha
Este projeto consiste em um programa desenvolvido em Python para analisar a força de uma senha com base nos critérios básicos de segurança. O sistema verifica se a senha possui pelo menos 8 caracteres,letras maíusculas, números e caracteres especiais. Para cada requisito atendido, é atribuída uma pontuação, que ao final classifica a senha com Fraca,  Média ou Forte
